/** * BSC TEXTILES — DAILY ATTENDANCE APP (v3) * BOUND script — open via the Sheet's Extensions → Apps Script. * Deploy as Web App (Execute as: Me, Access: Anyone). * JSONP (GET + callback) throughout — reads AND writes — to avoid CORS issues * calling from GitHub Pages.
